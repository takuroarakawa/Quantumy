# Dr.CANVAS 権利・法務運用（面談持参用1ページ）

## 1. 基本方針
- 著作権・ライセンス順守を事業設計に組み込む。
- 「引用だから安全」とはせず、原典ごとに利用条件を確認する。

## 2. 論文利用ルール（公開前チェック）
1. 権利者・発行元・ライセンス種別を確認
2. 出典URL/DOI/著者情報を記録
3. 引用利用は必要最小限・明確区分・出所明示
4. 翻案/図表利用が必要な場合は許諾取得

## 3. AI生成物ルール
- AI使用時は生成工程をログ化（モデル、日時、プロンプト概要）
- 既存作品との高類似が疑われる出力は公開停止
- 商用不可ライセンス素材は商用導線へ掲載しない

## 4. 投稿プラットフォーム運用
- 投稿者に権利保有/許諾有無の表明保証を求める
- 通報窓口（権利侵害申立）を設置
- 申立受領時に非公開化・反論受付・再公開判断を実施

## 5. 想定資料（必要時提出）
- 利用規約
- 投稿規約
- 二次創作ガイドライン
- 収益分配規程
- 削除申立対応フロー

## 6. 面談での説明文
> 法務リスクは事後対応ではなく、公開前審査と証跡管理で予防します。  
> 原典情報・ライセンス・AI生成履歴を一元管理し、継続運営可能な体制を構築します。
